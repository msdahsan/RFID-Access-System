# RFID-Access-System

An embedded Arduino-based RFID access validation system featuring an RFID reader, LCD display, and buzzer feedback mechanism. The project validates RFID tag scans and provides real-time visual and audio responses for authorized and unauthorized access attempts.

<img width="1331" height="998" alt="image" src="https://github.com/user-attachments/assets/2bb38fbf-6e75-4536-9f90-c8cf44f77464" />

## Overview

This project demonstrates a simple RFID authentication system built using Arduino hardware. When an RFID tag is scanned, the system compares the tag UID against a predefined list of authorized identifiers.

The system provides:
LCD feedback for system status and scan results
Buzzer alerts for successful or denied scans
Real-time RFID validation
A compact foundation for access control or attendance systems
